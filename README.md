# Element Fundamentals

Laboratório interativo sobre a rigidez de elementos sólidos lineares e quadráticos do Ansys, com uma mola helicoidal.
Este repositório contém apenas o site publicado; o código-fonte e a preparação dos dados ficam num repositório privado.
